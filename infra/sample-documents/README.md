# Documentos de ejemplo

Documentos inventados de la tienda para probar la subida (paso 7) y, después, la
ingesta y las preguntas del asistente (pasos 8 a 11). Ningún dato es real.

| `envios.md` | Política de la tienda | Ninguno (general) |
| `manual-samsung-galaxy-s25-ultra.md` | Manual | Samsung Galaxy S25 Ultra 256 GB |
| `manual-apple-iphone-16-pro.md` | Manual | Apple iPhone 16 Pro 256 GB |
| `manual-google-pixel-9.md` | Manual | Google Pixel 9 128 GB |

| `manual-hp-victus-15l.md` | Manual | HP Victus 15L |

| `manual-nintendo-switch-2.md` | Manual | Nintendo Switch 2 |
| `manual-microsoft-xbox-series-s.md` | Manual | Microsoft Xbox Series S 512 GB |

Hay un manual por cada producto de los datos de ejemplo (`SampleData.cs`), con las
mismas especificaciones de RAM, almacenamiento y pantalla que la base de datos.

Se suben desde `http://localhost:4200/documents`, eligiendo el producto en el caso de
los manuales. Este README no se sube.
